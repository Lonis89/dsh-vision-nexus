# Vision Nexus 视觉增强

给不具备直接看图能力的文本主模型提供**可验证、可量化**的视觉能力。所有图像信息都必须通过工具调用获取：原图与 base64 都不进入模型上下文，工具只返回结构化文本、坐标、置信度与产物 ID。

## 它解决什么问题

纯文本模型面对截图、UI 稿、图表、长文档时会靠脑补编造细节。本插件把「看」拆成一组可单独验证的量化操作，让模型的每一条视觉结论都能追溯到一次工具调用和一条审计记录。

## 提供的工具

渐进模式下，会话中先只暴露 `vision_activate`（省下整套 schema 的提示词开销）。首次需要视觉能力时调用它，会一次性挂载下列工具，并返回本会话已登记的图片、当前可用能力与机器可读的能力边界。

| 工具 | 能力 |
|---|---|
| `vision_detect` | 元素检测：组件清单、编号、像素坐标框、逐元素置信度 |
| `vision_ground` | 按文字描述定位目标，返回坐标框（需远端 VL 后端） |
| `vision_glance` | 图像问答 / 内容描述（需远端 VL 后端） |
| `vision_crop` | 按坐标裁剪子图，产物可被后续工具反复引用 |
| `vision_long_ocr` | 长截图分段结构化 OCR，输出带位置标记的 Markdown |
| `vision_pixel_diff` | 两图量化比对：差异占比、坐标清单、差异热力图产物 |
| `vision_extract_foreground` | 抠图 / 去背景，输出带 alpha 的产物 |
| `vision_color_extract` | 主色板、十六进制色值、各色占比与置信度 |
| `vision_trace_svg` | 位图轮廓转为 SVG 矢量 |
| `vision_html_render_snapshot` | 渲染 HTML 并截图，用于 UI 复现的像素级校验 |

## 引擎与降级

按 `本地 CV → 自定义 VL 后端 → 内置兜底 VL → WASM OCR` 的顺序降级，每次降级都写入审计，并在结果里明确告知模型当前能力限制——降级后不能做的事会被说清楚，而不是给出看似正常的猜测。

- **本地 CV**：Python + Pillow/NumPy 完成像素级计算，无需联网。
- **远端 VL**：自定义后端按优先级路由，密钥只在调度层内部解析。
- **运行模式**：`auto` 自适应；`local-only` 只用本地像素计算；`remote-only` 只用远端 VL。

## 产物与隔离

每张图片按会话隔离存放，工具输出 `art:...` 形式的产物 ID，后续工具可直接用该 ID 引用（裁剪图再取色、再比对都可）。产物按保留策略自动清理，不长期占用磁盘。

## 隐私边界

原图与 base64 不进入模型上下文；凭据不落配置文件、不进入模型上下文；导出的配置文本经过密钥抹除，可直接分享排障。

## 使用前提与已知限制

- 像素计算类工具需要本机可用的 Python 及 Pillow/NumPy；缺失时插件自动降为纯路由模式并禁用这类工具，不会静默给出错误结果。
- `vision_glance` / `vision_ground` 需要配置至少一个远端视觉语言后端，未配置时它们不会出现在可用工具列表中。
- WASM OCR 仅在宿主提供适配器时启用，否则保持结构化降级。
- 设置面板用于健康自检、引擎配置与限流调整；面板路由依赖宿主的 HTTP 服务，无该服务的宿主上仅面板部分不可用，视觉工具不受影响。
